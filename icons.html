Hora icon

The same dawn sky as Caelum and Consensus Weather, now with a frosted glass dial, bold rounded hands and a glowing blue timer ring.

Where the files go

Put every PNG into the icons folder of the Hora project, next to icon.svg, and keep the file names exactly as they download. icon-1024.png is the one to use anywhere you just want a nice picture of the icon, like the GitHub README or a social preview.
